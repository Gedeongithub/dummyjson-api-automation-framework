## DummyJSON API Automation Framework
### Project Overview

This project demonstrates a complete API Automation Framework built using Postman, executed via Newman, and integrated with Jenkins for CI/CD.

The framework validates REST APIs from the DummyJSON service, focusing on:

Functional testing
Schema validation
Data-driven testing
Automated reporting
Continuous Integration
### Tools & Technologies
Postman – API development & testing
Newman – CLI runner for Postman collections
Jenkins – CI/CD automation
Node.js – Runtime for Newman
newman-reporter-htmlextra – HTML reporting
GitHub – Source control
